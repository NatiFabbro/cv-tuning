# Desarrollador/a Frontend Junior — Pixelvalle Software

**Ubicación:** Remoto (LATAM) · **Modalidad:** full time

En Pixelvalle desarrollamos aplicaciones web para empresas de salud y educación. Buscamos sumar a una persona junior a nuestro equipo de producto.

## Qué vas a hacer
- Desarrollar interfaces con React junto a diseño y backend.
- Convertir diseños de Figma en componentes reutilizables y accesibles.
- Participar en revisiones de código y en las dailies del equipo.

## Requisitos
- Experiencia previa (laboral, pasantías o proyectos) con **React** y **JavaScript**.
- **TypeScript** (excluyente).
- HTML y CSS sólidos; conocimientos de accesibilidad web.
- Manejo de **Git** y flujos con pull requests.
- Nivel de inglés para leer documentación técnica.

## Suma
- Experiencia con **Next.js** o **testing con Jest**.
- Conocimiento de **Storybook**.

Somos un equipo cercano y buscamos personas con ganas de aprender.
